# Gemini 4 Argon: почему сигналы разошлись по каналам

Проверено по продакшену 30 сентября 2026 года (время ниже — Europe/Istanbul). Локальная база не использовалась.

## Что произошло

- **23:05** — `gemini-models-blog` (событие `47726`) и `deepmind-blog` (`47727`) одновременно увидели официальный пост Google. Оба события записаны, получили класс `article` и были подавлены для `discord-trail` с причиной `a_post_about_the_company_not_a_model`.
- **23:19** — Arena Text зафиксировала дебют `gemini-4-argon-high` на **#1** (`47730`); карточка отправлена в `discord-signals` и `tg-news`. В той же коллекции Arena Code показала **#8** (`47739`), но событие подавлено с причиной `no_reader_facing_change` — «outside the top 3».
- **23:36–23:38** — Hacker News принёс ссылку на тот же пост Google (`47749`); именно этот поздний `article` был отправлен в `discord-trail`. Официальные события туда не отправлялись.
- **23:56** — очередной опрос Artificial Analysis успешно получил 687 моделей, включая `Gemini 4 Argon (High)` с Intelligence Index **52,6** (на скриншоте округлено до **53**). Событие `47780` записано как `debut`, внутренний ранг **#8**, но для обоих публичных каналов подавлено с причиной `no_reader_facing_change` — «outside the top 3». `speaks=0`, доставки нет.

## Причины

1. **Доступ к Artificial Analysis работает.** Ключ на проде готов; за предыдущие сутки было 23 попытки сбора без ошибок. Сборщик читает `/api/v2/data/llms/models`. Это не отказ API и не задержка очереди.
2. **Порог классификации и порог отправки расходятся.** `src/events/boardSignals.ts` называет новый результат в топ‑10 `debut`; `src/events/notification.ts` и `src/events/worth.ts` пропускают отдельную карточку только в топ‑3. Поэтому исчезли и Arena Code #8, и AA #8. `preview 47780` умеет нарисовать карточку, но не отменяет решение о подавлении.
3. **Внутренний ранг AA не равен месту на выбранном графике сайта.** Парсер в `src/sources/analysis.ts` сортирует все оценённые API-варианты по точному баллу. Режимы Max, Xhigh и High считаются разными строками. У Argon балл 52,6 и место #8 в этой сортировке; скриншот показывает округлённые 53 и сравнение меньшего набора моделей. Правило сопоставления места на графике с рангом API отдельно не проверено.
4. **Официальный пост Google ошибочно прошёл как обычная статья.** `newsClass` в `src/events/newsrooms.ts` ищет в заголовке слова вроде `Introducing`/`Announcing`; заголовок «Gemini 4 Argon: our next era of frontier intelligence» такого слова не содержит, хотя описание начинается с `Announcing`. Затем `isAboutTheCompanyNotAModel` в `src/events/worth.ts` не нашёл Argon среди уже известных API-моделей и подавил пост.

## Практический итог

Оценка AA **не выйдет позже сама**: событие уже обработано и подавлено, а `daily-recap` на проде выключен. Повторный часовой опрос не создаст повторного `new` для той же строки.

Следующая правка должна согласовать порог новых дебютов с отправкой, сохранив строгий фильтр для обычных движений рейтинга; показать Code #8 рядом с Text #1 без второй однотипной карточки; и распознавать официальный анонс модели по содержанию поста, когда заголовок не начинается с глагола анонса. Изменение читательских карточек нужно проверить через `bun run rehearse --needed`. Для уже подавленного `47780` потребуется отдельное решение об отправке: изменение кода задним числом сообщение не создаст.
